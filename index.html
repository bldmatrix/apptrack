Gmail Setup
One-time setup — 5 minutes
After this, just tap Sync Gmail and your emails auto-organize. You never repeat this step.
1
Open Google Cloud Console
Go to console.cloud.google.com and sign in with your Gmail.
2
Create a new project
Top dropdown → New Project → name it AppTrack → Create.
3
Enable Gmail API
Left menu → APIs & Services → Library → search Gmail API → Enable.
4
Configure OAuth consent screen
APIs & Services → OAuth consent screen → External → fill App name (AppTrack) and your email → Save. Add scope: gmail.readonly. Add yourself as Test User.
5
Create OAuth Client ID
Credentials → Create Credentials → OAuth client ID → Web application.
Under Authorised JavaScript origins, add your app URL (e.g. https://yourusername.github.io).
Also add http://localhost for testing.
6
Copy your Client ID below
From Credentials page, copy the Client ID — it looks like: 123456789-abc...apps.googleusercontent.com
AppTrack requests read-only Gmail access only.
Emails are never stored on any external server.
